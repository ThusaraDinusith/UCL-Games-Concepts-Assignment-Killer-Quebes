# Killer Quebes

A 2D game prototype developed in C++ as part of university coursework. 

## Features
* Custom 2D game loop and rendering
* Real-time keyboard/mouse input handling
* Collision detection and scoring mechanics
* Level design utilizing structured scene and waypoint configurations

## Project Structure
* `.cpp` / `.h` — Core source code and game logic
* `scene.txt` — Level and scene configuration files
* `waypoints.txt` — Waypoint layout and navigation data

## Requirements
* C++ compiler (Visual Studio, GCC, or MinGW)
